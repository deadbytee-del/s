How to use

  1. Drop a file or .zip on the left.
  2. Type what you want done.
  3. Paste 3 OpenRouter keys (free at openrouter.ai/keys).
  4. Press Start session.
  5. Watch the 3 AIs work. Press Stop when done.
  6. Press Download to get your files.
Found a bug? Type it in the Bugs box.
